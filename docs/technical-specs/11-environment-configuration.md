# 11. Environment Configuration

Every variable below is validated at boot by `src/lib/env.ts` (Zod schema); an invalid or missing required value fails immediately with a readable error rather than falling back silently. `drizzle-kit`, `scripts/*.ts`, and `src/proxy.ts` are the only code allowed to read `process.env` directly, for the reasons documented in `src/lib/env.ts`'s own header comment.

## 11.1 Per-environment summary

| Variable                               | Development          | Production        |
| -------------------------------------- | -------------------- | ----------------- |
| `REDIS_URL`                            | Optional             | Required          |
| `ENABLE_RESET_API`                     | May be set to `true` | Must be unset     |
| `BETTER_AUTH_SECRET` placeholder value | Allowed (warns)      | Rejected (throws) |
